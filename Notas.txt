Se puede aplicar el puppet localmente con
> sudo /opt/puppetlabs/bin/puppet apply --modulepath=./modules ./manifests/default.pp

1)
ABRIR DOS VENTANAS DE POWERSHELL
vagrant ssh puppetmaster
vagrant ssh puppetclient

en ambas maquinas 
sudo apt-get update
sudo apt-get install dos2unix

y hacer dos2unix en TODOS los ficheros:
->script, hosts, puppet.conf


2) Ejecutar los siguientes scripts que ya actualizan el /etc/hosts. Si no funcionan, revisar dominios. ej: server=puppetmaster.ita.es y tambien en /etc/hosts
./puppetMaster/script.sh
./puppetClient/script.sh

EN PUPPETMASTER->
sudo vim /etc/puppetlabs/code/environments/production/manifests/site.pp

   node 'puppetclient' {
      file { '/newfolder':
      ensure => 'directory',
      }

      file { '/newfolder/hola.txt':
         ensure => present,
      }
   }

EN PUPPETCLIENT
sudo /opt/puppetlabs/bin/puppet agent --test
